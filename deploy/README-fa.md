**MTF** یک پنل مانیتورینگ و فیلاور سلف‌هاست دوزبانه (فارسی/انگلیسی، RTL/LTR) است که:
**۸۲ متد تونل واقعی** را تست می‌کند، سرورها را با نمودارهای زنده زیر نظر می‌گیرد،
همه تانل‌های درحال‌اجرای روی سرورهای شما را شناسایی می‌کند، با **یک کلیک** تانل
ماندگار جدید نصب می‌کند و به‌صورت **خودکار پورتِ بدونِ تداخل** روی IPv4 و IPv6 انتخاب می‌کند.

## ۱. توضیح تک‌تک دکمه‌ها و بخش‌ها

### ۱.۱ نوار بالا

| عنصر | کارکرد |
|------|--------|
| **لوگو + MTF** | نشان برند؛ سه میله نماد فعالیت تونل‌هاست. |
| **نقطه ضربان + ساعت** | ضربان زنده پنل؛ هر ثانیه به‌روز می‌شود. |
| **بج AUTO / MANUAL** | حالت فیلاور فعلی. فیروزه‌ای = خودکار، کهربایی = دستی. |
| **بج تانل فعال** | تونلی که در لحظه VIP `10.10.10.5` را حمل می‌کند؛ در حالت بی‌کاری «بدون تانل فعال». |
| **دکمه کره EN / FA** | جابه‌جایی کل رابط بین فارسی (RTL) و انگلیسی (LTR)؛ انتخاب در `localStorage` ذخیره می‌شود. |
| **آیکون در** | خروج — کوکی نشست را پاک می‌کند. |

### ۱.۲ ریل کناری (۸ تب)

| تب | هدف |
|----|-----|
| **داشبورد** | KPI‌ها + ۶ نمودار زنده + تایم‌لاین رویدادها. |
| **تانل‌ها (۸۲)** | رجیستری کامل ۸۲ متد: انتخاب، اعمال، سوییچ دستی. |
| **تانل‌های سرورها** | اسکن سرورها برای یافتن تانل‌های موجود + نصب ماندگار یک‌کلیکی بین دو سرور. |
| **پورت‌ها و تداخل** | اسکنر تداخل پورت/پروتکل و تخصیص خودکار پورت. |
| **پروب سرورها** | پروب SSH سرورهای دلخواه (OS، کرنل، کیفیت لینک). |
| **پیشنهاد تونل** | پیشنهاد رتبه‌بندی‌شده تونل برای هر جفت سرور. |
| **استقرار روی سرور** | اجرای هارنس تست ۸۲ متد روی یک سرور واقعی از طریق SSH. |
| **تنظیمات** | آستانه‌های فیلاور، حالت، و اعتبار ورود پنل. |

### ۱.۳ تب داشبورد

| ویجت | خوانش |
|------|-------|
| کارت‌های KPI **تانل فعال / VIP / آپ از کل / حالت** | وضعیت لحظه‌ای فیلاور. |
| نمودار سطحی **سلامت میزبان — CPU / RAM** | پنجره متحرک ۱۰ دقیقه‌ای با نمونه‌برداری ۵ ثانیه‌ای از `/proc`؛ برچسب مقدار مستقیم (نه فقط رنگ). |
| نمودار خطی **ترافیک شبکه** RX/TX | نرخ بایت هر ثانیه؛ RX خط ممتد فیروزه‌ای، TX خط‌چین کهربایی. |
| دونات **وضعیت ۸۲ متد** | سهم UP / تقلیل‌یافته / در حال استقرار / خطا / خاموش + جدول راهنمای عددی. |
| گیج **امتیاز سلامت** | عدد مرکب ۰ تا ۱۰۰: تانل‌های تأییدشده + فضای CPU + پاداش بدون‌خطا. |
| تایم‌لاین **رویدادهای زنده** | هر ورود/نصب/پروب/سوییچ، تازه‌ترین اول، با نقطه شدت. |
| نمودار میله‌ای **تأخیر بهترین تانل‌ها** | کم‌RTTترین متدهای پروب آخر با برچسب ms مستقیم. |

### ۱.۴ تب تانل‌ها (۸۲ متد)

| کنترل | رفتار |
|-------|-------|
| **جست‌وجو** | فیلتر زنده بر اساس شناسه/نام. |
| **چک‌باکس ستاره‌دار** | فقط سه خانواده شاخص: HEDIOUM، HAJSAMAN، PAQET. |
| **چیپ‌های خانواده** | ۱۳ خانواده (SSH، GOST، FRP، RATHOLE، CHISEL، WSTUNNEL، VPN، XRAY، SING-BOX، WATERWALL، PAQET، COMPOSITE، KERNEL). |
| **چک‌باکس ردیف‌ها** | صف‌کردن متدها برای استقرار. |
| **اعمال انتخاب‌شده‌ها** | استقرار + تأیید هر متد با هارنس کرنلی/یوزراسپیس؛ وضعیت UP / DEGRADED / ERROR با رسید. |
| **سوییچ دستی** | روتینگ VIP را به آن متد می‌برد و پنل را دستی می‌کند. |
| **جدول رسیدها** | آخرین نتایج PASS/PARTIAL/FAIL با شواهد خام. |

### ۱.۵ تب تانل‌های سرورها — اسکن و نصب یک‌کلیکی

| کنترل | رفتار |
|-------|-------|
| **ردیف سرورها (هاست/پورت/یوزر/رمز)** | هر تعداد هدف SSH. **رمزها هرگز ذخیره نمی‌شوند** — فقط در حافظه برای اسکن/نصب. |
| **+ افزودن سرور** | ردیف جدید. |
| **اسکن همه سرورها** | به هر سرور (و خود پنل) SSH می‌زند و شناسایی می‌کند: اینترفیس‌های تونل کرنلی (GRE/SIT/IPIP/VXLAN/VTI/ERSPAN…)، پیرهای WireGuard، پروسس‌های یوزراسپیس (gost، xray، sing-box، chisel، frp، rathole، wstunnel، hysteria، tuic، …)، یونیت‌های systemd و لیستنرها — هر چیزی که خود پنل ساخته با برچسب «مال پنل». |
| **انتخابگر سمت A / سمت B** | دو سر سرور تانل جدید (A = کلاینت، B = سرور). |
| **چک‌باکس حالت جفتی** | روشن = تانل واقعی دوسویه (یونیت systemd روی هر دو میزبان)؛ خاموش = فقط سمت کلاینت. |
| **کاتالوگ نصب (۴۱ پروفایل)** | هر متد را تیک بزنید — WIREGUARD، GRE، VXLAN، VTI، IP6GRE، OPENVPN، GOST×۴، CHISEL×۲، WSTUNNEL×۲، RATHOLE×۲، FRP×۳، VLESS×۷، HYSTERIA2، TUIC، TROJAN، SHADOWSOCKS، SSH×۳ — سپس **نصب موارد تیک‌خورده**. |
| **نوار و لاگ نصب** | پیشرفت زنده هر متد + خطوط خام SSH. |
| **جدول کتاب نصب‌شده‌ها** | هر تانل نصب‌شده روی هر سرور با نتیجه و نام یونیت؛ دکمه **حذف شد** یونیت‌ها، اینترفیس‌ها، کانفیگ‌ها را برمی‌چیند و پورت را آزاد می‌کند. |

### ۱.۶ تب پورت‌ها و تداخل (ایمنی سرور عمومی)

| کنترل | رفتار |
|-------|-------|
| **اسکن پورت‌ها** | همه لیستنرهای TCP/UDP هر سرور (`ss -tulnpH`). |
| کارت‌های **TCP اشغال / UDP اشغال / پروتکل‌های IP** | در دموی زنده ۴۷+ لیستنر پیدا شد؛ بخش IP، اشغال GRE/IPIP/SIT/ESP را نشان می‌دهد. |
| **جدول لیستنرها** | سرور · پروتکل · پورت — نقشه «چه چیزی مال کیست». |
| **تخصیص خودکار پورت** | متد + ترنسپورت را انتخاب کنید → مدیریتی پورت برمی‌گزیند که: داخل رنج امن باشد (TCP 21000–25999، UDP 26000–29999)، روی **همه** سرورها آزاد باشد، در لیست ۴۸ پورت سیستمیِ همیشه‌رزرو نباشد (22، 53، 80، 443، 3306، 5432، 6379، 9443…)، قبلاً تخصیص نیافته باشد. برای v4 و v6 یکسان است چون هر دو جدول لیستنر خوانده می‌شود. |
| **جدول تخصیص‌ها** | تخصیص‌های جاری با دکمه آزادسازی. پایپ‌لاین نصب قبل از نوشتن کانفیگ دوباره اسکن و تأیید می‌کند. |

### ۱.۷ تب پروب سرورها

| کنترل | رفتار |
|-------|-------|
| **ردیف سرورها + اجرای پروب** | اثرانگشت SSH هر سرور: OS، نسخه کرنل، تأخیر SSH، IPهای سراسری، آپ‌تایم. |
| **کارت‌های نتیجه** | بج OK/FAIL برای هر میزبان با جزئیات. |
| **ماتریس قابلیت‌ها** | کیفیت لینک زوج‌به‌زوج: RTT با ICMP (یا fallback به TCP)، لاس٪، جیتر. |

### ۱.۸ تب پیشنهاد تونل

- دکمه **محاسبه پیشنهاد** هر جفت پروب‌شده را امتیاز می‌دهد (۰ تا ۱۰۰) و بهترین
  خانواده‌های تونل را با **دلیل دوزبانه** لیست می‌کند (مثلاً «لینک پرلاس →
  WaterWall / paqet روی QUIC بهترین ریکاوری»، «UDP بلاک → chisel روی TCP خالص»).
- سه خانواده انتخابِ مالک (HEDIOUM، HAJSAMAN، PAQET) همیشه لیست می‌شوند.

### ۱.۹ تب استقرار روی سرور

| کنترل | رفتار |
|-------|-------|
| **هاست / پورت SSH / یوزر / رمز** | ماشین هدف. |
| **همه متدهای تأییدشده** | مجموعه PASS+PARTIAL را مستقر می‌کند؛ تیک را بردارید تا از انتخاب تب تانل‌ها استفاده شود. |
| **شروع استقرار** | نتایج هر متد (نتیجه + شواهد) در جدول جاری می‌شود. |

### ۱.۱۰ تب تنظیمات

| کنترل | رفتار |
|-------|-------|
| **سگمنت حالت** | فیلاور خودکار یا دستی. |
| **Cooldown / Hysteresis / لاس تقلیل / لاس قطع / RTT تقلیل / فاصله پروب** | کل سطح تنظیم FSM. |
| **ذخیره تنظیمات** | آستانه‌ها ذخیره و همان لحظه در موتور اعمال می‌شود. |
| **کارت اعتبار** | تغییر نام‌کاربری/رمز پنل (در `data/panel_secret.json`). |

## ۲. چرا منحصربه‌فرد است؟

- **دیزاین‌سیستم «کنسول عملیات»** — توکن‌محور (primitive → semantic → component)
  با متدولوژی ui-ux-pro-max: کنتراست WCAG-AA روی بوم سرمه‌ای عمیق، اکسنت‌های
  داده فیروزه‌ای/کهربایی، ریتم فاصله ۴/۸، مجموعه آیکون SVG (بدون ایموجی)،
  حلقه focus-visible، پشتیبانی reduced-motion و **موتور نمودار SVG کاملاً
  خودنویس بدون وابستگی** (خط/سطح، میله، دونات، گیج) با برچسب مقدار مستقیم و
  نمودارهای قابل‌فوکوس با کیبورد.
- **دوزبانه در طراحی** — یک دیکشنری، فارسی (RTL، وزیرمتن) و انگلیسی (LTR) را
  می‌راند؛ جهت بدون شکستن چیدمان عوض می‌شود.
- **صفر CDN** — فونت، آیکون، JS و CSS همه از داخل کانتینر سرو می‌شوند؛ روی
  شبکه بسته هم اجرا می‌شود.

## ۳. قابلیت‌های شبکه

| قابلیت | نحوه |
|--------|------|
| **مدیریت تداخل پورت** | اسکن زنده `ss` برای هر سرور + اشغال پروتکل‌های IP + پورت‌های سیستمی رزرو + دفتر تخصیص. |
| **تخصیص خودکار پورت** | رنج‌های قطعی (TCP 21000–25999، UDP 26000–29999) که قبل از نصب روی **همه** سرورها آزادی‌شان تأیید می‌شود؛ پایپ‌لاین نصب در زمان اجرا دوباره اسکن می‌کند. |
| **IPv4 + IPv6** | سرورهای یوزراسپیس دو-پشته بایند می‌شوند (`::` با v4-mapped)؛ WireGuard/GRE/IPIP/VXLAN/VTI علاوه بر v4 آدرس داخلی `fd00:173:x::/126` می‌گیرند؛ SIT/IP6GRE/IP6GRETAP/VTI6 بومی v6 با تشخیص خودکار IPv6 سراسری. |
| **نصب چندتوزیعه** | تشخیص مدیربسته در apt / dnf / yum / zypper / pacman / apk با نگاشت نام بسته‌ها (`wireguard-tools`، `openvpn`، `iproute(iproute2)`، …)؛ بازکردن فایروال با ترتیب ufw → firewalld → nftables/iptables. |
| **نصب ماندگار** | یونیت systemd روی میزبان‌های واقعی + حلقه supervisor داخل کانتینر، با ری‌استارت خودکار در بوت پنل. |

## ۴. شروع سریع

```bash
# روی میزبان پنل (هر لینوکس x86_64 با داکر)
sudo mkdir -p /opt/multitunnel && cd /opt/multitunnel
# مسیرها: engine/ panel/ docker/ bin/ certs/ (چیدمان مخزن)
docker network create mtfnet 2>/dev/null || true
docker run -d --name mtf-panel --restart unless-stopped \
  --network mtfnet -p 9443:9443 \
  --privileged --network_mode host \
  -v /opt/multitunnel/engine:/opt/multitunnel/engine \
  -v /opt/multitunnel/panel:/opt/multitunnel/panel \
  -v /opt/multitunnel/bin:/opt/multitunnel/bin \
  -v /opt/multitunnel/data:/opt/multitunnel/data \
  -v /opt/multitunnel/logs:/opt/multitunnel/logs \
  -v /opt/multitunnel/certs:/opt/multitunnel/certs \
  mtf-panel:2.0
# ورود: https://<host>:9443  (رمز بوت‌استرپ فقط یک‌بار در /api/password-hint)
```

اعتبارها در `/opt/multitunnel/data/panel_secret.json` نگهداری می‌شود و رمز
بوت‌استرپ تا اولین ورود نمایش داده می‌شود — بلافاصله در
**تنظیمات → اعتبار ورود** عوضش کنید.

## ۷. نکات امنیتی (حتماً بخوانید!)

- پنل **فقط پورت 9443** را با TLS بیرون می‌دهد؛ بقیه داخل شبکه داکر می‌ماند.
- رمزهای SSH برای اسکن/نصب **فقط در حافظه** هستند.
- ⚠️ در طول توسعه برخی اعتبارها در چت رد و بدل شده؛ پیش از اتکا به این استقرار
  **رمز root هر دو سرور، رمز پنل و توکن گیت‌هاب را تعویض کنید**.
