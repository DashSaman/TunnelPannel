## آزمون نرم‌افزار و انتشار

[CI نسخه نهایی](https://github.com/DashSaman/TunnelPannel/actions/runs/38963184697) و [بررسی امنیتی CI](https://github.com/DashSaman/TunnelPannel/actions/runs/38963184676) موفق‌اند. هر کدام از Python3.11 و3.12:۶۹۲ تست اصلی،۱۰۰ تست TunnelGuard و۱ تست backend. نصب تازه/تکراری، بازیابی با تغییر آزمایشی، حذف امن، ShellCheck، syntax، Ruff و قیود کاتالوگ موفق‌اند. ویندوز:۶۷۰ تست اصلی و۲۲ ردشدن مختص پلتفرم،۸۹ تست TunnelGuard و۱۱ ردشدن مختص پلتفرم و۱ تست backend موفق. هشدارهای منسوخ‌شدن وابستگی‌ها در لاگ باقی‌اند. [اعداد ماشینی](evidence/commercial/verification.json).

اشکال اولیه جمع‌آوری تست و PATH ویندوز در محیط اجرا رفع شد؛ رفتار محصول تغییر نکرد. چند فرض اشتباه اسکریپت پذیرش درباره session، نام فیلد منبع و پیشوند سرویس SSH پس از خواندن خطای کامل اصلاح شد. محافظ قطع کنترلر در اجرای دیرهنگام بدون کشتن سرویس توقف امن داشت. نصب‌کننده ویرایش موقت CSS آزمایشی را بازنویسی نکرد؛ فقط همان فایل متعلق به آزمون با هش تأییدشده به اصل برگشت و نسخه ثابت نصب شد. لاگ خام و آرشیو خصوصی روی سرورها می‌مانند؛ رمزها وارد ریپو نشده‌اند.

## نصب و دسترسی

```sh
curl -fsSL https://raw.githubusercontent.com/DashSaman/TunnelPannel/d757fa836db2ddf838bb1f6897fbb3e30cde3a9c/install.sh | sudo env TUNNELPANNEL_VERSION=d757fa836db2ddf838bb1f6897fbb3e30cde3a9c bash
```

صفحه `/portal` را با SSH forward باز کنید؛ API اصلی فقط روی127.0.0.1:8080 گوش می‌دهد. دو حساب خصوصی تحویل وجود دارد: مدیر اصلی و مشتری نمایش گروه‌های۷+۵. مشخصات در فایل خصوصی جداگانه و `/root/tunnelpannel-commercial-access.txt` روی A است. کلید API قابل‌حدس قبلی لغو شد. پس از تحویل، رمز و MFA خودتان را تنظیم کنید. بکاپ فعلی هر سرور در `/root/tp-commercial-acceptance/handoff-current.tar.gz` به همراه checksum است؛ کلید رمزگذاری نصب را جدا نگه دارید و دیتابیس رمز‌شده دو نصب را باهم عوض نکنید.

پایش گروه‌های اصلی صریحاً با فاصله۶۰ ثانیه فعال است. هنگام این ثبت، **858.1 ثانیه** گذشته و28 نمونه و6 رویداد مانده بود. هفت روز سقف نگهداری است و آزمون SLA هفت‌روزه انجام نشده است. هشدار فعلاً داخل پنل است. گواهی عامل۳۰ روز اعتبار دارد و پیش از انقضا باید چرخانده و فایل جدید نصب شود.

گردش کار: ساخت فضای مشتری ← دعوت ← فعال‌سازی آزمایشی ← ثبت SSH سرورها ← برآورد ← تست ← پیشنهاد با رسید واقعی ← انتخاب خودکار یا دلخواه ← فیل‌اور/تقسیم اتصال. هر مقصد ورودی SOCKS مستقل دارد. بیش از۵ عضو به سقف پلن و فضای کار وابسته است. تقسیم روی اتصال‌های TCP جدید است؛ اتصال قبلی پس از خرابی دوباره وصل می‌شود. همه تونل‌های منتهی به یک مقصد، با خاموش‌شدن همان مقصد از دست می‌روند. تجمیع تک‌دانلود و VPN کامل UDP/IP ادعا نشده‌اند.

## نیازهای بیرون از این دو سرور برای فروش عمومی

دامنه و HTTPS مورد اعتماد، درگاه و checkout واقعی، آزمایش ایران و چند کشور، آزمون طولانی‌تر و بار چندمشتری به اطلاعات یا زمان جدا نیاز دارند. قیمت و checkout تنظیم نشده و هیچ پولی دریافت نشده است. SMTP و اعلان بیرونی هم تنظیم نشده‌اند. این نسخه برای بتای دعوتی آماده شده و هنوز سرویس عمومی پولی با SLA تأییدشده نیست.

کد و شواهد در [شاخه PR2](https://github.com/DashSaman/TunnelPannel/pull/2) منتشر می‌شوند؛ دستور ثابت مستقل از merge شدن main کار می‌کند. محدودیت تأیید ابزار گیت‌هاب برای مشخصات PR/main دور زده نشده است.
