# مدیریت پایدار تهران‌نتورک

مالک در ۳۱ اکتبر ۲۰۲۶ تأیید کرد هر دو سرور تست حذف شده‌اند. فایل‌های سایت باقی مانده بود، اما API روی یکی از همان سرورها قرار داشت. پراکسی پاسخ HTML با خطای502 می‌داد و صفحه آن را JSON فرض می‌کرد. نسخهٔ اصلاحی، بخش مدیریت را به کانتینر دائمی و مستقل منتقل می‌کند و خطای ارتباط را فارسی/انگلیسی و قابل فهم نشان می‌دهد.

## تفکیک کارها

ورود، کاربران، پلن‌ها، ثبت پرداخت دستی، سهمیه و نتایج در کانتینر مدیریت نگهداری می‌شوند. این بخش فقط کارها را از طریق SSH با اثر انگشت ثبت‌شده هماهنگ می‌کند. تست سرعت، فرمان‌های اندازه‌گیری، ساخت تونل، فوروارد و عبور ترافیک روی سرورهای ثبت‌شدهٔ مشتری انجام می‌شود. درخواست‌های دوره‌ای برای وضعیت، کار سبک مدیریتی هستند.

کانتینر مدیریت یک پردازش API با کاربر10001، فایل‌سیستم اصلی فقط‌خواندنی، بدون مجوزهای کرنل، بدون Docker socket و بدون شبکهٔ میزبان دارد. سقف فعلی512MiB رم و نیم هسته CPU است؛ این سقف اجرایی است و تضمین ظرفیت یا سرعت نیست. پایگاه‌داده در مسیر خصوصی دائمی خارج کانتینر می‌ماند. سایت و پراکسی قبلی مستقل‌اند.

حالت `TP_CONTROL_PLANE_ONLY=1` بدون فهرست IPهای میزبان در `TP_CONTROLLER_EXCLUDED_HOSTS` راه نمی‌افتد. آدرس‌های سرور تهران‌نتورک، لوپ‌بک و سرورهای حذف‌شده نباید نود اجرای تونل شوند. نام دامنه قبل از ارسال رمز بررسی و اتصال به همان IP بررسی‌شده انجام می‌شود. پراکسی مورد اعتماد فقط gateway شبکهٔ اختصاصی Docker است؛ مبدأ عمومی HTTPS باید صریح تنظیم شود.

## اطلاعات بازیابی‌شده

بکاپ قابل بازیابی مربوط به **۱۸ اکتبر ۲۰۲۶ ساعت17:24:57UTC** و شامل پنج فضای کاری و شش حساب است. اطلاعات جدیدتر، از جمله مصرف و آزمایش‌های بعدی، از این بکاپ قابل بازسازی نیست. تاریخ بکاپ و هشدار تاریخی‌بودن وضعیت‌ها برای مدیر نمایش داده می‌شود؛ وضعیت قدیمیِ فعال، مشاهدهٔ زنده نیست.

فایل رمزگذاری‌شدهٔ اولیه و کلید مستقل آن حفظ می‌شوند. کارهای معلق قدیمی به حالت قطع‌شده می‌روند و پایش قدیمی خاموش می‌شود، اما ورودی، تنظیمات، نتایج و تاریخچه حذف نمی‌شوند. هیچ استقرار قدیمی دوباره اجرا نمی‌شود و اتصال به IPهای حذف‌شده پیش از ارسال رمز رد می‌شود.

ابزار آفلاین `python -m scripts.control_plane_admin` ورودی خصوصی JSON را از stdin می‌گیرد: `username`، `password` و فقط برای بازیابی قدیمی `retire_pending:true`. باید در کانتینر متوقف با مسیر دادهٔ صحیح اجرا شود. ابزار ساختار دیتابیس را ارتقا می‌دهد، حساب‌های دیگر را حفظ می‌کند و فقط مدیر صریحاً انتخاب‌شده را می‌سازد یا به‌روز می‌کند. رمز در تصویر، آرگومان فرمان یا ریپو قرار نگیرد؛ نشست‌های قدیمی دوباره معتبر نشوند.

تعویض کانتینر باید با همان مسیر داده و کلید رمزگذاری نصب انجام شود. پیش و پس از ارتقا، از دیتابیس اصلی، registry و تمام فضاهای کاری بکاپ سازگار SQLite بگیرید؛ env و کلید نصب را جدا و خصوصی نگه دارید، آرشیو را رمزگذاری و تطبیق رمزگشایی/هش را بررسی کنید و نسخه‌ای خارج میزبان داشته باشید. بکاپ روی VPS حذف‌شده در دسترس نخواهد بود. بکاپ تاریخی را روی دادهٔ جدید فعال بازنویسی نکنید.

## کار مدیر

از [ورود به پنل](https://tehnet.ir/tunnels/portal) با حساب مدیری که خصوصی تحویل شده وارد شوید. در «مدیریت کاربران و فروش»، فضای مشتری و حسابش را بسازید، پلن و محدودیت‌ها را تنظیم کنید و پس از دریافت واقعی مبلغ، پرداخت دستی و فعال‌سازی را ثبت کنید. درگاه آنلاین یا پرداخت ساختگی اضافه نشده است.

حساب‌های یک فضای مشتری، سهمیهٔ مشترک دارند؛ برای مشتری مستقل فضای جدا بسازید. سقف حجم، سقف کل دوره است. برای حفظ مصرف، گزینهٔ «دورهٔ جدید» خاموش بماند. تخصیص100GiB به معنی انتقال100GiB داده نیست. [راهنمای تصویری سهمیه و مهاجرت](ADMIN-WALKTHROUGH-fa.md) جزئیات را دارد. مهاجرت به سرور مبدأ زنده و تنظیمات اصلی نیاز دارد؛ سرور حذف‌شده قابل مهاجرت نیست و گروه تاریخی نباید بازسازی شود.

برای کار جدید، نودهای مشتری را ثبت و بررسی کنید و سپس برآورد و شروع تست را بزنید. اکنون سرور تست واقعی در اختیار نیست؛ نتیجهٔ جدید دو سرور، سرعت یا فایروال نباید ادعا شود. قابلیت منابع/فایروال در شاخهٔ جدا هنوز نصب و پذیرش نهایی نشده است.

## وضعیت بررسی

خطای HTML ابتدا در تست بازتولید و سپس اصلاح شد. اجرای تازهٔ تست‌های ویندوز935موفق،52وابسته به POSIX اجرا‌نشده و دو هشدار قبلی داشت. کانتینر واقعیِ آزمایشی، ورود، ساخت مدیر/کاربر، رد درخواست بدون CSRF، اجرای بدون root و حفظ اطلاعات پس از ری‌استارت را بررسی کرد؛ ابزار تونل داخل آن نصب نیست. مشاهدهٔ حدود79MiB رم مربوط به حالت سبک آزمایشی است، نه بنچمارک بار. CI نسخهٔ ثابت و انتشار واقعی سایت مرحلهٔ جداست؛ این سند نسخهٔ آمادهٔ بررسی است و رسید نصب نهایی محسوب نمی‌شود.
