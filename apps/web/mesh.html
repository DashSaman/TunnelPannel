۱ · افزودن سرور

کلید SSH در اولین اتصال ثبت و سپس بررسی می‌شود. برای پین‌کردن کلیدی که از قبل تأیید کرده‌اید، از API ثبت سرور استفاده کنید.

۲ · آزمایش همهٔ مسیرها

انتخاب روش‌های آزمایش

آزمایش و ساخت منابع فقط روی سرورهای انتخاب‌شده انجام می‌شود. نتیجهٔ موفقِ بدون اندازه‌گیری واقعی ساخته نمی‌شود؛ اگر کمتر از پنج گزینه تأیید شوند، همان تعداد نمایش داده خواهد شد.

۴ · اتصال‌های فعال و فیل‌اور

هر مقصد ورودی SOCKS مستقل دارد. اتصال‌های جدید هنگام خرابی به گزینهٔ سالم منتقل می‌شوند؛ اتصال TCP قبلی باید دوباره وصل شود. خرابی کامل مقصد با چند تونل به همان سرور پوشش داده نمی‌شود.
